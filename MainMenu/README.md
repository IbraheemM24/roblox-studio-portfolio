# 🎮 Roblox Main Menu System

##  Overview

The **Main Menu System** is a user interface developed in Roblox Studio that serves as the primary entry point for players when they launch the game. It features a custom GUI with four interactive buttons: **Play, Settings, Credits, and Quit**, allowing players to navigate the main menu and access different options.

A dedicated **Camera Part** is used as the camera's focal point, creating a controlled viewpoint for the main menu instead of relying on the player's default camera position. This helps establish the game's atmosphere before the player begins playing.

The system combines GUI design, camera control, and button interactions to provide a simple and accessible menu experience.

## Features

- **Play Button** – Allows players to start the game and transition from the main menu into gameplay.
- **Settings Button** – Provides access to the settings interface, where players can configure available game options.
- **Credits Button** – Displays information about the developers and contributors involved in the project.
- **Quit Button** – Provides an exit option in the menu interface. Since Roblox does not allow standard in-game scripts to directly close the Roblox client, this button can instead return the player to another screen or display an exit confirmation.
- **Custom Camera System** – Uses a dedicated Camera Part as the focal point for the main menu camera.
- **Interactive GUI** – Uses clickable GUI buttons to allow players to navigate the menu.
- **Modular Menu Structure** – Separates the main menu from additional interfaces, making the system easier to maintain and expand.
