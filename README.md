# Roblox Studio System Showcase

A showcase of game systems I built in Roblox Studio.

## Main Menu

A clean, animated menu that showcases game title and allows player to choose when they want to start the game/  It works on PC, mobile, and console.

## Anti-Cheat

A server-side anti-cheat that catches common exploits like speed hacking and teleporting. The server makes the final call on everything, so the client can't be trusted to cheat its way through.

## Combat System

A responsive combat system with attacks, blocking, and dashing. Hits are checked on the server to keep fights fair.

## Technology

Roblox Studio
Luau (Lua)
## About the Repository

This repo is part of my portfolio and shows how I build and organise game systems in Roblox. Download it and open the .rbxl file in Roblox Studio to try it out.

## KEY TAKEAWAY
**AI** was used as a supporting tool for research, debugging, and problem-solving,not to create the entire project. Development also involved my own knowledge, skills, independent research, and YouTube tutorials. As AI can make mistakes and produce incorrect results, human judgement and verification remain essential. I believe AI should assist developers rather than replace them, as human understanding, creativity, and responsibility are still necessary to ensure the final product works correctly.

**Note:** Not every script used in the project has been included in this repository. Only scripts I considered meaningful, useful, or relevant to showcasing my development work have been published.
